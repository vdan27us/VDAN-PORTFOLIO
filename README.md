# Vidhan Prajapati — Research Portfolio

A React + Vite portfolio for machine learning work across healthcare, medical imaging, IoT time-series analysis, privacy-preserving AI, and environmental intelligence.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`. Run `npm run lint` for ESLint checks.

## Content and interaction notes

- Projects, research experience, and innovation records are separate sections.
- Research Playground charts use generated synthetic signals. They are educational explainers, not live sensors, trained-model inference, or clinical tools.
- Publication URLs and Kaggle profile URL were not present in the supplied material, so no links to them are published.
- The supplied resume is served from `public/Vidhan_RESUME.pdf`.
